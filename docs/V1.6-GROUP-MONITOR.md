# Social Manager V1.6 - Group Monitor

V1.6 adds persistent Facebook Group assets and a rate-limited Group Monitor to the local Facebook Operator Agent.

## Safety model

- Uses the user's normal persistent Chrome profile.
- Does not bypass login, CAPTCHA, 2FA, checkpoint or security review.
- AUTO mode requires explicit keywords (or `watch_all=true`) and an explicit `reply_message`.
- MEDIUM/HIGH-risk content is never auto-replied; it is marked `NEEDS_REVIEW`.
- Default rate limit: maximum 3 replies/hour per monitor, maximum 2 replies/scan.
- Seen posts are deduplicated in SQLite.

## Commands through bridge/facebook-command.json

Remember a Group so later commands can use its name:

```json
{
  "id": "remember-group-001",
  "action": "facebook_operator",
  "operator_action": "remember_group",
  "payload": {
    "group_name": "Hội kỹ thuật cửa cuốn Việt Nam",
    "group_url": "https://www.facebook.com/groups/.../"
  }
}
```

Start safe automatic monitoring:

```json
{
  "id": "monitor-group-001",
  "action": "facebook_operator",
  "operator_action": "monitor_group",
  "payload": {
    "group_name": "Hội kỹ thuật cửa cuốn Việt Nam",
    "keywords": ["motor", "động cơ", "tủ điều khiển", "cửa cuốn"],
    "mode": "AUTO",
    "reply_message": "Chào anh/chị. Bên mình có kinh nghiệm về nội dung này. Anh/chị có thể cho biết model, tải cửa và hiện tượng cụ thể để trao đổi chính xác hơn.",
    "poll_seconds": 180,
    "max_replies_per_hour": 3
  }
}
```

Use `mode=DRAFT` to only collect matching discussions without publishing replies.

Stop a monitor:

```json
{
  "id": "stop-monitor-001",
  "action": "facebook_operator",
  "operator_action": "stop_monitor_group",
  "payload": {
    "group_name": "Hội kỹ thuật cửa cuốn Việt Nam"
  }
}
```

Post to a remembered Group by name:

```json
{
  "id": "post-group-001",
  "action": "facebook_operator",
  "operator_action": "post_group",
  "payload": {
    "group_name": "Hội kỹ thuật cửa cuốn Việt Nam",
    "message": "Nội dung bài đăng",
    "image_url": "https://example.com/public-image.png"
  }
}
```

## Run local operator agent

```bash
npm run operator:login
npm run operator:agent
```

The operator agent includes the command poller, Group Monitor scheduler and the browser worker. Facebook UI changes can move a job to `NEEDS_REVIEW`; review the operator status/screenshot instead of adding stealth or bypass logic.
